## Ethics Statement

This repository is created strictly for educational and defensive cybersecurity learning purposes.

All experiments and observations documented here were performed on the author’s own system and network environment. No third-party systems, networks, or users were targeted, tested, or affected.

This project does not include:
- Exploitation techniques
- Bypass methods for security controls
- Instructions for illegal or unauthorized activity

The purpose of this work is to:
- Understand how modern tracking and fingerprinting mechanisms operate
- Improve defensive awareness and security knowledge
- Encourage responsible and ethical behavior in cybersecurity practice

Knowledge of security mechanisms does not imply permission to abuse them. Users of this repository are expected to follow all applicable laws, policies, and ethical standards.
